# Brompton 3D Printing Parts

A collection of 3D-printed parts designed for the Brompton folding bike (with a Pendix mid-drive conversion). Each part lives in its own folder with its own README, source CAD/print files, `pics/` gallery, and license.

> **Status:** first-attempt prototypes, both currently in use. See each part's README for open TODOs.

## Parts

- [Stem Bag Holder](stem-bag-holder/README.md) — second support point for a stem/handlebar bag, using a printed bearing collar
- [Triangle Clamp for Pendix](triangle-clamp-for-pendix/README.md) — anti-rotation bracket for the Pendix battery holder
